Modul

Pasang PASOPATI ke sistem yang sudah ada.

Modul Python dengan fungsi berbahasa Indonesia: paraf perintah, periksa perintah, buka kanal aman, dan catat logistik.

pasopati-modul-purwarupa.zip

v0.1.0 · Python 3.10+ · berisi modul, contoh, panduan

Unduh modul
Versi purwarupa untuk evaluasi. Bukan untuk operasi nyata. Di dunia nyata, modul sandi militer tidak disebar bebas, tetapi didistribusikan secara terkendali lewat PUSSIBERAD.

Cara memasang

  1. Unduh dan ekstrak zip-nya.
  2. Pasang kebutuhan: pip install -r requirements.txt
  3. Coba contoh: python contoh.py
  4. Impor ke sistemmu: from pasopati import …
Contoh pemakaian
from pasopati import Identitas, Registri, Penerima, paraf_perintah

puskom = Identitas.buat("PUSKOM", "KOMANDO")
alfa = Identitas.buat("SATUAN-ALFA", "SATUAN")
registri = Registri(puskom, alfa)

perintah = paraf_perintah(puskom, "SATUAN-ALFA",
                          {"operasi": "Patroli Sektor 7"}, nomor_urut=1)

print(Penerima(alfa, registri).periksa(perintah))
# DITERIMA
#   ✔ Identitas pengirim terdaftar
#   ✔ Tanda tangan ML-DSA-65 valid
#   ✔ Anti-replay …
Isi modul

Fungsi yang tersedia

FungsiKegunaan
Identitas.buat(nama, peran)Membuat kunci paraf ML-DSA-65 dan kunci tukar ML-KEM-768 + X25519
Registri(...)Daftar node tepercaya beserta kunci publiknya
paraf_perintah(...)Memaraf perintah dengan nomor urut, waktu, dan nonce
Penerima(...).periksa(...)Memeriksa identitas, wewenang, paraf, tujuan, masa berlaku, dan kiriman ulang
buka_kanal(a, b, registri)Kanal hibrida bertanda tangan; .segel() dan .buka() memakai AES-256-GCM
RegisterLogistik(...).catat() catatan berparaf dan .audit() seluruh rantai
